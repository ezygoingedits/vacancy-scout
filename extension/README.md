# Vacancy Scout Chart Bridge

Install in Chrome with Developer mode → Load unpacked, selecting this folder. Start Vacancy Scout at http://localhost:3000 first, then open the official IRCTC vacancy chart in another tab. Open the extension popup and enable capture. The extension observes only the exact vacantBerth response. If it arrives during page startup before the capture switch signal is received, the normalized berth records remain in page memory for up to 60 seconds; they are transferred and saved locally only after capture is enabled. No cookies, passwords, authorization headers or request bodies are read. The records are not sent to a cloud service by this extension.

If this extension folder was already loaded in Chrome, open chrome://extensions and click the refresh icon for Vacancy Scout Chart Bridge after replacing the folder with the updated version. Then refresh the IRCTC chart and select the journey again. Return to Vacancy Scout and click Analyze chart after the JSON field populates.

This prototype does not bypass login, CAPTCHAs, authorization or access controls and cannot know whether a TTE later assigns a berth. Confirm data-source terms and authorization before public distribution.
